- Register: modern spoken Odia (conversational), not literary. Prefer spoken verb forms.
- Sentence end: Western full stop `.`, not daṛi `।`. Treat any `।` the same way. Inside flowing speech, replace the stop with `;` when the same argument continues, or `-` when the same thought continues. Keep it only where the thought truly closes.
- Use `!` instead of the full stop when a point ends in a clipped, non-grammatical way.
- Respect: address the listener with ଆପଣ/ଆପଣଙ୍କ. Drop a repeated pronoun; the verb ending carries person/honorific.
- ✗ ପ୍ରାଣର ସଂକେତ → ✓ ପ୍ରାଣ-ସଂକେତ (samasa shortens phrase)
- ✗ ଭଲ → ✓ ଶ୍ରେୟସ୍କର (better = spiritually preferable)
- ✗ ସଚେତନ ଭାବରେ → ✓ ସଙ୍କଳ୍ପ ସହ (intent: deliberately, not consciously)
- ✗ ତଫାତ → ✓ ପାର୍ଥକ୍ୟ (precise contextual word)
- ✗ ସବେ ପଚାରୁଛନ୍ତି, "<quote>" → ✓ ସବେ, "<quote>" - ବୋଲି ପଚାରୁଛନ୍ତି (speech verb after quote)
