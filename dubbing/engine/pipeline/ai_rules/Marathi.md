- Register: modern spoken Marathi (बोलीभाषा / सहज मराठी), never शुद्ध or साहित्यिक. Use boli forms: करीत आहे → करतोय, झालेले आहे → झालंय. Drop a/an/the; drop a pronoun when the verb ending or context carries the subject.
- Sentence end: daṛi `।`, never ".". While the same argument is still building, use `;` (or `-`) instead of `।`; don't end every line with `।`.
- Use `!` instead of `।` when a point closes in a non-grammatical tail after the main idea, e.g. आरक्षण आणले होते - त्यांना थोडी चांगली संधी देण्यासाठीच!
- Quotes: subject, "quote", then असं + verb: प्रत्येक जण, "सद्‌गुरू, तुम्ही यासाठी एवढं डोकं का खर्ची घालता?" - असं विचारतात।
- ✗ मानतात → ✓ पाहत असले तरी (closer to "known to be")
- ✗ खरं सांगायचं तर → ✓ मुळात ("essentially", not contradiction)
- ✗ त्यांना त्रास होतो → ✓ त्यांना वेदना होतात (pain, not suffering)
- ✗ जप-बिप सगळं → ✓ जप वगैरे सगळं (jap and such things)
- ✗ तुम्हाला माहीत आहे का → ✓ माहीत आहे ना (spoken short form)
